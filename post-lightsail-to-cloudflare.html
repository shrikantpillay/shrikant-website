Why I am moving my personal site away from AWS Lightsail

I originally built this website on AWS Lightsail for two reasons: to get hands-on experience with AWS, and to create a place where I could share experiments, lessons and real-world technology observations.

What changed?

The website does not require a continuously running application server. Most of the content is static, while the Lightsail instance continues to consume infrastructure cost even when I am not publishing anything.

The experiment

I am testing a much simpler model: store the website in GitHub and publish it using Cloudflare Pages. Every change committed to GitHub can automatically trigger a new deployment.

What I want to learn

  • How simple a production website can be without a traditional server.
  • How Git-based deployment changes the publishing workflow.
  • How much infrastructure cost can be removed from a low-traffic personal site.

This page itself is part of that experiment.
