# Shrikant Pillay site

Static blog built with Eleventy, edited with Pages CMS, hosted on Cloudflare Pages.

Cloudflare Pages settings:
- Production branch: main
- Build command: npm run build
- Build output directory: _site

Pages CMS:
- Open https://app.pagescms.org
- Sign in with GitHub
- Install the Pages CMS GitHub App for this repository
- Open the repository; `.pages.yml` defines the Blog Posts editor
- new!
